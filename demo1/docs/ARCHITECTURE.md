# System Architecture - Dream Learn BD

## Frontend
- HTML5, CSS3 (Tailwind CSS, FontAwesome 6, Google Fonts Hind Siliguri & Outfit)
- Reactive State Engine with LocalStorage persistence
- Multi-Role Support: Super Admin, Principal, Teacher, Student, Guardian
- Responsive, Accessible, and Print-Ready layouts for Marksheets and Student ID Cards

## Backend & API
- Node.js & Express.js REST API
- PostgreSQL Relational Database Schema & Migrations
- Docker & Docker-Compose production setup
